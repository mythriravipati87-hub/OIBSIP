
Personal Portfolio Website

 About the Project
A responsive personal portfolio website built to showcase my background, technical skills, projects, and contact information.

 Objective
To create a professional online portfolio using HTML5 and CSS3 as part of the Oasis Infobyte Web Development and Designing internship.

 Technologies Used
- HTML5
- CSS3
- Google Fonts
- CSS Flexbox and Grid
- Responsive Media Queries

 Features
- Sticky navigation bar
- Introduction and profile section
- About Me section
- Technical skills grid
- Project showcase cards
- Contact section with social links
- Smooth scrolling navigation
- Responsive desktop and mobile layout

 Project Structure
- index.html — Website content
- style.css — Styling and responsive design
- screenshots/ — Project screenshots

 How to Run
1. Download or clone this project.
2. Open index.html in a web browser.
3. Navigate through the Home, About, Skills, Projects, and Contact sections.
