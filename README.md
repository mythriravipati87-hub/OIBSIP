NovaTech Landing Page

 Project Overview
NovaTech is a modern, responsive landing page created as
part of the Oasis Infobyte Web Development Internship.

 Technologies Used
- HTML5
- CSS3
- CSS Flexbox and Grid
- Responsive Media Queries

 Features
- Sticky navigation bar
- Hero section with call-to-action links
- Three feature cards
- About section
- Contact footer
- Smooth scrolling
- Responsive mobile layout

 How to Run
1. Download or clone this project.
2. Open index.html in a web browser.

Purpose
This project demonstrates fundamental HTML and CSS
skills, page layout, and responsive web design.
